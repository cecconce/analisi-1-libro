# Analisi Matematica 1 – libro di studio

Appunti di Pierluigi Ceccon per Analisi Matematica 1 (Ingegneria Elettronica, Meccatronica e Robotica, Università di Udine), in forma di libro HTML: teoria, grafici, esercizi svolti ed errori da evitare.

**Leggi online:** https://cecconce.github.io/analisi-1-libro/

Capitoli: logica e insiemi, intervalli, numeri complessi, funzioni reali, limiti e continuità, derivate, successioni e serie, serie di potenze, integrali, funzioni razionali, integrali impropri, a cosa servono gli integrali. In arrivo: più variabili ed equazioni differenziali.

Materiale di studio personale. Non contiene dispense, eserciziari o temi d'esame del docente.
